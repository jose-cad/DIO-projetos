# Guia de Colaboração em Projetos Open Source no GitHub

Este repositório foi desenvolvido como parte do desafio prático da **DIO** sobre colaboração em projetos **Open Source** utilizando as principais ferramentas do GitHub.

---

## 🚀 Fluxo de Contribuição Open Source

O fluxo padrão para contribuir em projetos de código aberto no GitHub segue os seguintes passos:

1. **Fork do Repositório**
   - Cria uma cópia completa do repositório original no seu perfil pessoal.

2. **Clone Local**
   - Baixa o repositório forkado para a sua máquina de desenvolvimento:
     ```bash
     git clone [https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO.git](https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO.git)
     ```

3. **Criação de Branch Temática**
   - Isolamento de novas funcionalidades ou correções (*bugfixes*):
     ```bash
     git checkout -b feature/minha-contribuicao
     ```

4. **Commits e Envio de Alterações**
   - Salvar as alterações locais e enviá-las para o seu fork remoto:
     ```bash
     git add .
     git commit -m "feat: adiciona minha contribuicao"
     git push origin feature/minha-contribuicao
     ```

5. **Abertura do Pull Request (PR)**
   - No GitHub, navegue até o repositório original e abra um **Pull Request** detalhando as alterações propostas para análise dos mantenedores.

---

## 🛠️ Recursos do GitHub para Open Source

- **Issues:** Para relatar bugs, sugerir novas *features* ou discutir ideias.
- **Pull Requests (PRs):** Para propor alterações de código e passar por *Code Review*.
- **Discussions:** Fórum da comunidade para dúvidas e anúncios.
- **GitHub Actions:** Automação de testes (CI/CD) para garantir a qualidade das contribuições.
- **CONTRIBUTING.md:** Arquivo com as regras e diretrizes do projeto para novos colaboradores.
